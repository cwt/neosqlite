# NX-27017 v0.8.0 Release Notes

NX is now the single async story for NeoSQLite: point `AsyncMongoClient`
at it and every `await` works with no wrapper library.

## Multi-database isolation (P0)

- One SQLite file per logical database (`--data-dir`), created on
  demand; `:memory:` is per-database isolated. Plain file `--db`
  stays legacy-shared unless `--single-db-compat` is passed.
- Real `dropDatabase` (close + unlink) and per-file `listDatabases`
  sizes; sessions scoped `(lsid, db)`.
- Invalid database names are rejected before touching the filesystem.

## Correctness (P0)

- Real cursor pagination: `find`/`aggregate` honor `batchSize`
  (default 101) with server-side `getMore`/`killCursors` and a 16MB
  BSON batch cap.
- Change streams are pull-based over the shared trigger log (persistent
  `Collection.watch()` per db/collection, no threads): resume tokens,
  `resumeAfter`/`startAfter` replay, `$match` filtering,
  `fullDocument` modes, per-db isolation. Covers bulk, TTL and
  direct-SQL writes the old push fan-out missed.
- Wire namespaces use the logical database name, never the file path
  (broke `getMore` round-trips once real cursor ids existed).
- `commit/abortTransaction` resolve across session scopes (drivers
  commit on `admin.$cmd` while the transaction lives on the data db).

## Parity (P1)

- Bulk: per-op `writeErrors`, `upserted` ids, matched counts, and the
  client-level `bulkWrite` verb (wire version bumped 21 -> 25).
- Search: `createSearchIndexes` / `updateSearchIndex` /
  `dropSearchIndex` mapped onto FTS, `$listSearchIndexes` served from
  metadata, `$text` verified over the wire.
- TTL specs round-trip; auto-purge on count/distinct/aggregate.
- `arrayFilters` forwarded on update; `count` honors limit/skip.
- GridFS: dotted `fs.files`/`fs.chunks` routed for drop/distinct/count
  and direction-aware sort; legacy and bucket APIs verified live.
- `writeConcern` mapped per database onto SQLite PRAGMAs.
- `OP_QUERY` frozen as a legacy fallback; `find_raw_batches` has no
  wire verb on either side.

## Verification

- NX suite: 157 passed. Main suite: 3012 passed.
- Async wire-vs-wire differential vs real MongoDB 8.2.12 (podman):
  17/17 green (core, bulk, transactions, change streams, admin).
- Localhost benchmark (3k docs): ~1.9x wire tax on writes, ~30ms per
  full scan. Full-suite A/B vs v1.17.1: 3.87s vs 3.90s.

## Known leniencies

Invalid hints are ignored (real errors), non-default-locale collation
order and `maxTimeMS` are best-effort, single documents over 16MB are
returned whole, generic dotted collection names are unsupported, and
there is no cross-database atomicity. See `../IMPROVEMENT_PLAN.md`.
