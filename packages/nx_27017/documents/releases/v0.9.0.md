# NX-27017 v0.9.0 Release Notes

NX-27017 v0.9.0 aligns the wire-protocol server with NeoSQLite v1.18.1 and the Python 3.12 minimum runtime.

## Breaking Changes

- **Python 3.12+ is required.** Python 3.10 and 3.11 are no longer supported.
- The package remains compatible with `neosqlite >= 1.17.4, < 2.0.0` and is tested against NeoSQLite v1.18.1.

## Packaging

- The `speed` extra now declares `uvloop` directly.
- The package metadata advertises the Python 3.12, 3.13, 3.14, and 3.15 classifiers automatically.
- `Requires-Python` is `>=3.12,<3.16`.

## Modernization

The server code follows the same Python 3.12 cleanup as NeoSQLite v1.18.1: `datetime.UTC`, `typing.Self`, `asyncio.run(..., loop_factory=...)`, `str.removeprefix()`, `collections.abc` imports, and hoisted standard-library imports.

## Verification

- **180 passed, 1 skipped** in the nx-27017 test suite on Python 3.12, 3.14, and 3.15.
- Ruff, mypy, and Black are clean.
