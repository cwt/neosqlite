# NeoSQLite v1.17.0 Release Notes

## TL;DR

NeoSQLite v1.17.0 is a **minor feature and parity release** delivering comprehensive transactional hardening, PyMongo API parity expansions, and 100% compatibility across the differential test suite. It resolves 42 itemized findings spanning transactions, bulk writes, aggregation engines, BSON codecs, GridFS, and storage migration.

**Key Highlights:**
1. **Transaction Context Managers & Session Propagation** — `ClientSession.start_transaction()` supports the Python context manager protocol (`with session.start_transaction(): ...`), with robust session validation and pass-through across operations like `find_one(..., session=session)`.
2. **Full Bulk Write Architecture & Parity** — Added `BulkWriteError`, `upserted_ids`, duck-typed request matching, and full `ordered=True` vs `ordered=False` execution semantics with failure accumulation.
3. **Aggregation System Variables & Expressions** — Added support for `$$ROOT` and `$$CURRENT` system variables and dictionary template expressions in `$group` accumulators, `%L` millisecond formatting in `$dateToString`, and composable `$dateDiff` with nested date arithmetic expressions.
4. **Data Safety, Storage Integrity & Security Hardening** — Ensured WAL checkpointing and compliant backup file naming during auto-vacuum migration, prevented SQL injection in `$lookup` aliases and collection names, sanitized FTS5 queries against syntax injection, prevented silent GridFS data loss on non-autocommit connections, and eliminated thread race conditions in `ObjectId` counter generation.
5. **Type & Query Parity** — Converted `ObjectId.generation_time` to a timezone-aware UTC datetime property; `$currentDate` now sets proper BSON Date objects deserialized as Python `datetime.datetime`; exact `_id` types are preserved without string-to-ObjectId coercion; and `list_collection_names()` cleanly excludes internal SQLite, metadata, and FTS5 shadow tables.

## Detailed Changes

### Transactions and Sessions
* **Context Manager Protocol:** `ClientSession.start_transaction()` now implements `__enter__` and `__exit__`. Exiting the `with` block commits the transaction on clean exit and aborts on uncaught exceptions.
* **Session Validation & Pass-Through:** `Collection.find_one()` now accepts and validates the `session` parameter, forwarding it to the query engine and GridFS read paths. Sessions from mismatched database connections are rejected with `ValueError`.
* **Change Stream Isolation:** `Collection.watch()` no longer calls `self.db.commit()`, ensuring active transactions on the connection are not prematurely committed by opening a change stream.

### Bulk Write Engine
* **`BulkWriteError` Exception:** Failed bulk operations raise `BulkWriteError` containing detailed error diagnostics (`writeErrors`) and partial execution results (`nInserted`, `nModified`, `nMatched`, `nRemoved`, `nUpserted`).
* **Unordered Execution (`ordered=False`):** Execution continues past errors to process subsequent write models, accumulating all errors before raising `BulkWriteError`.
* **Request Matching & Upsert Tracking:** Write models support duck-typing (e.g. custom or third-party write request classes), and `BulkWriteResult.upserted_ids` accurately maps the original batch index to generated or specified `_id`s.

### Aggregation Pipeline
* **`$$ROOT` and `$$CURRENT` System Variables:** Supported in `$group` accumulators (e.g. `{"$push": "$$ROOT"}` or `{"$push": "$$CURRENT"}`) across both SQL Tier 1 and Python tiers.
* **Dictionary Templates & Literals in `$group`:** Accumulators accept nested object templates and literal values (e.g. `{"$push": {"user": "$name", "active": True}}`).
* **Composable Date Expressions:** `$dateDiff` unwraps nested BSON date objects generated by `$dateAdd`, `$dateSubtract`, `$dateFromParts`, or `$dateTrunc`, preventing SQLite `julianday()` `NULL` failures. Python fallback normalizes timezone awareness when computing differences.
* **Date Formatting (%L):** Supported the `%L` millisecond format specifier in `$dateToString` across SQL and Python tiers.
* **Month and Year Rollover:** `$dateAdd` and `$dateSubtract` clamp month-end overflows to the final day of the target month rather than spilling into subsequent months.
* **Stage Corrections:** `$bucket` routes boundary overflows to the `default` bucket without creating phantom buckets; `$densify` validates that `step` is strictly positive; `$limit` rejects negative values.

### Query Engine and CRUD
* **Accurate Modified Counts:** `update_one` and `update_many` accurately compare before and after document states, incrementing `modified_count` only when documents actually changed.
* **Array Filters & Pull Conditions:** `array_filters` are supported consistently across update operations. `$pull` supports query filter conditions (`$gt`, `$in`, etc.) and nested dotted paths.
* **Missing Field Query Parity:** `$ne: null` and `$in: [..., null]` query semantics match missing document fields in accordance with MongoDB specification across SQL and Python tiers.
* **Canonical BSON Comparison Order:** `$cmp` implements standard BSON type precedence across both SQL and Python tiers.
* **Cursor Limit Semantics:** `find().limit(-1)` returns at most 1 document (batch-size semantics); `find().limit(0)` returns all matching documents.
* **Atomic Find-and-Modify Projections:** `find_one_and_update`, `find_one_and_replace`, and `find_one_and_delete` now properly apply the `projection` argument to returned documents.
* **Clean Collection Listing:** `Connection.list_collection_names()` and `list_collections()` filter out SQLite system tables (`sqlite_%`), NeoSQLite metadata tables (`_neosqlite_*`, `neosqlite_*`), and FTS5 virtual/shadow tables (`*_fts`, `*_fts_*`).
* **Dummy Collection Cleanliness:** `Connection.cursor_command()` passes `create=False` when constructing the dummy collection for `AggregationCursor`, avoiding physical table creation in SQLite.

### BSON Codecs and Type System
* **Preserve String `_id`:** Fixed automatic coercion of 24-character hex strings into `ObjectId`. Documents inserted with string `_id` preserve their exact string type on disk and retrieval.
* **`ObjectId.generation_time`:** Converted from a naive datetime method/property into a property returning a timezone-aware UTC `datetime.datetime`.
* **Date and Binary Deserialization:** Plain ISO-8601 strings are no longer coerced into `datetime` objects on read; only explicit BSON `{"$date": ...}` markers decode to `datetime`. Dictionaries containing binary-like markers without valid data are preserved as dicts rather than marked as corrupted.
* **`$currentDate` Update Operator:** Stores a BSON Date object decoded as a Python `datetime.datetime`, matching MongoDB behavior.

### Security and Storage Integrity
* **Auto-Vacuum WAL Checkpoint:** `migrate_autovacuum()` invokes `prepare_for_backup()` to checkpoint WAL files to the database before snapshotting, preventing data loss when active readers hold locks.
* **SQL Injection Hardening:** Collection names in `$unionWith`, `$graphLookup`, and `$lookup` are quoted with `quote_table_name()`. The `as` alias in lookup hash-joins is validated and quoted.
* **FTS5 Query Sanitization:** User text search strings are sanitized to escape special characters, quotes, and punctuation that could trigger SQLite syntax errors or injection.
* **FTS Maintenance on Collection Rename:** Renaming a collection automatically renames associated FTS5 virtual tables, shadow tables, triggers, and index metadata.
* **GridFS Non-Autocommit Protection:** `GridIn.close()` explicitly commits transactions, preventing silent data loss upon connection close when `autocommit=False`.
* **GridFS Custom ObjectId & Chunk Size:** Streaming uploads with custom `ObjectId` reliably create files documents; custom `chunk_size_bytes` is respected during chunk slicing.
* **Thread-Safe `ObjectId`:** Counter increments across threads are protected against race conditions.

## Installation & Upgrading

### Installation

```bash
pip install neosqlite==1.17.0

# With NX-27017 MongoDB wire protocol server:
pip install "neosqlite[nx27017]==1.17.0"

# With uvloop high-performance networking (Linux/macOS):
pip install "neosqlite[nx27017-speed]==1.17.0"
```

### Upgrading from v1.16.x to v1.17.0

1. **`ObjectId.generation_time` returns timezone-aware UTC datetime**:
   If application code compared `oid.generation_time` with naive `datetime.now()`, update comparisons to use `datetime.now(timezone.utc)` or `datetime.utcnow().replace(tzinfo=timezone.utc)`.
2. **24-character string `_id` preservation**:
   Documents inserted with string `_id` (`{"_id": "507f1f77bcf86cd799439011"}`) now return `str` rather than being coerced into `ObjectId`.
3. **`$currentDate` returns `datetime.datetime`**:
   Fields updated via `$currentDate` now deserialize into `datetime.datetime` objects rather than ISO text strings.
